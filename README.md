# Калькулятор на Java (Console Calculator)

Учебный проект в рамках курса Java. Консольное приложение для выполнения базовых арифметических операций с поддержкой непрерывных вычислений.

- Поддерживаемые операции: сложение (`+`), вычитание (`-`), умножение (`*`), деление (`/`).
- Управляющие команды:
  - `C` или `c` — сбросить текущий результат и начать заново.
  - `S` или `s` — выйти из программы.
- Защита от деления на ноль: при попытке деления на ноль выводится ошибка, а текущий результат не меняется.
- Непрерывные вычисления: результат предыдущей операции становится первым числом для следующей.

Для запуска понадобится установленный JDK (версия 11 или выше).

1. Клонируйте репозиторий (или скачайте файл `Calculator.java`).
2. Откройте терминал в папке с проектом и выполните компиляцию:
   javac Calculator.java
3. Запустите прогамму
   java Calculator.java
